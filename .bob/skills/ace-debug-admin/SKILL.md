# ACE Debug Admin skill

## Purpose

Help to determine and fix issues when calling administration MCP tools from this MCP Server.

## When to use

- The user is seeing errors with MCP Tools from this MCP Server

### Procedure

- Check all relevant skills are loaded and in use
- Check user is providing sensible prompts that align with skills in use
- Check the user has the permissions to do the requested operations
- Do not ever change permissions or access levels
